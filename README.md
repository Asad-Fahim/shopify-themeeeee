# Shopify Theme - Nasir Books

A comprehensive Shopify theme implementation for a book store with custom functionality, responsive design, and multi-language support.

## Features

- **Custom Sections**: Extensive collection of customizable sections including hero banners, product showcases, testimonials, and more
- **Design System**: Complete visual guidelines and design system for consistent branding
- **Wholesale Functionality**: Dedicated wholesale pages and features for B2B customers
- **Multi-language Support**: Localization for multiple languages (Arabic, German, Spanish, Finnish, French, Italian, Japanese, Norwegian, Polish, Portuguese, Swedish)
- **Responsive Design**: Mobile-first approach with optimized layouts for all devices
- **Advanced Product Features**: Quick buy, pre-order, product recommendations, and recently viewed products
- **Custom Templates**: Specialized templates for blogs, collections, customer accounts, and wholesale pages

## Theme Structure

```
/
├── assets/              # CSS, JavaScript, and SVG assets
├── config/              # Theme settings and configuration
├── layout/              # Main theme layout files
├── locales/             # Translation files for multiple languages
├── sections/            # Reusable theme sections
├── snippets/            # Reusable code snippets
├── templates/           # Page templates (JSON and Liquid)
└── documentation/       # Design guides and implementation docs
```

## Key Components

### Sections
- **Hero Sections**: Slideshow, image with text overlay, wholesale hero
- **Product Sections**: Featured product, product recommendations, shop the look
- **Content Sections**: Rich text, testimonials, timeline, FAQ
- **Navigation**: Header with mega menu, mobile menu, footer
- **E-commerce**: Cart, mini-cart, collection listing, product grid

### Templates
- **Product Pages**: Standard product, pre-order, quick buy variants
- **Collection Pages**: Standard collection, list collections
- **Customer Pages**: Login, register, account, addresses, orders
- **Special Pages**: Wholesale, contact, FAQ, about us

## Installation

1. Download the theme files
2. Upload to your Shopify store via Admin > Online Store > Themes
3. Customize settings in the theme editor
4. Configure wholesale features and pricing rules
5. Set up multi-language settings in Shopify admin
